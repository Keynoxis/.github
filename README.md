## About the organization

Keynoxis is an open-source organization focused on hardware-backed identity, authentication, and access tools. We connect protected hardware capabilities with open standards and the developer tools people already use.

We believe strong security should not require proprietary lock-in, fragile integrations, or expert-only workflows. Our projects aim to make hardware roots of trust understandable, auditable, and useful across personal development environments and professional infrastructure.

## What we build

- Developer identity and access tools
- Integrations for Secure Enclave, FIDO2 security keys, and TPM
- Standards-based bridges for SSH and other existing workflows
- Clear documentation for deploying and operating hardware-backed credentials

## Our principles

- **Hardware-backed by design** — sensitive key material should remain inside protected hardware whenever possible.
- **Open and auditable** — security claims should be inspectable in source code and documentation.
- **Standards first** — new protection should work with established protocols and tools.
- **Usable security** — safer workflows must also be practical for daily work.
- **Vendor-aware, not vendor-locked** — projects should support multiple hardware roots of trust behind consistent interfaces.

## Current project

### [Keynoxis](https://github.com/keynoxis/keynoxis)

An open-source hardware-backed SSH agent for Secure Enclave, FIDO2 security keys, and TPM. It lets standard SSH, Git, and IDE workflows use protected identities without ordinary private-key files.

## Community
